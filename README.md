# Gaussian Classification Model — GBP/USD

Навчальний проєкт із прогнозування напрямку денної зміни GBP/USD за допомогою власних реалізацій гаусових класифікаторів та моделей scikit-learn.

## Файли

- `GBPUSD_Gaussian_Classification.ipynb` — ноутбук з поясненнями, графіками, кодом та обчисленими результатами.
- `GBPUSD_Gaussian_Classification.html` — HTML-версія ноутбука для перегляду без Python.
- `gbpusd_gaussian.py` — запуск у вигляді звичайної Python-програми.
- `data/GBP_USD Historical Data.csv` — вхідні історичні дані GBP/USD із [Investing.com](https://www.investing.com/currencies/gbp-usd-historical-data).
- `requirements.txt` — Python-бібліотеки.
- `results/output.txt` — текстовий вивід запуску Python-файла.
- `results/figures/` — збережені графіки.

## Як запустити

Потрібен Python 3.10 або новіший. У терміналі відкрийте папку з файлами проєкту та виконайте:

```bash
python -m pip install -r requirements.txt
python gbpusd_gaussian.py --no-show
```

Параметр `--no-show` зберігає графіки без відкриття вікон. Без цього параметра програма також показує графіки. Ноутбук можна відкрити в Jupyter або Visual Studio Code та виконати всі комірки послідовно.

## Методика оцінювання

Для бінарної задачі прогнозується знак дохідності наступного торгового дня (↑/↓). Для мультикласової задачі дохідність поділяється на три класи за терцилями.

- Навчальний період — 2010–2022 роки, незалежний тест — 2023–2026 роки.
- Відбір переможця мультикласового чемпіонату проводиться **тільки на навчальному періоді**: 8 фолдів `TimeSeriesSplit` з хронологічним порядком, балами за 5 середніх валідаційних метрик (macro ROC AUC OvR, accuracy, balanced accuracy, macro F1, log-loss).
- На кожному фолді межі класів і масштабування обчислюються **лише за train-частиною фолда**.
- За однакової суми балів вирішальною є середня валідаційна macro AUC.
- Після вибору переможця всі моделі навчаються на навчальному періоді та оцінюються на тесті. Результати тесту не змінюють рейтинг.

За цих правил переможець за валідаційною сумою балів — **Logistic Regression**, а найкраща власна гаусова модель — **In-house LDA**. Це не твердження про статистично доведену перевагу над кожною іншою моделлю.

## Уточнення методики

- Ймовірності власного класифікатора та sklearn збігаються до похибки обчислень після узгодження оцінки коваріації. Основні in-house моделі використовують ОМП-оцінку (`ddof=0`); для QDA/LDA можливі невеликі відмінності від sklearn.
- ACF дохідностей та їх модулів обчислюється за повним послідовним рядом після очищення, до фільтрації за цільовою змінною. ACF числових дохідностей не є ACF знаків їх зміни.
- Підтримується регуляризація коваріації; у наведених QDA/LDA експериментах `reg=0.0`.
- Відсутність значущої переваги за accuracy не означає відсутності будь-якого сигналу за AUC: NB має слабкий сигнал на тесті, але його стабільність у часі не підтверджена.
- Мультикласова задача використовує ту саму вибірку без нульових цілей. Довірчі інтервали та статистичні перевірки є наближеними й залежать від припущень щодо часового ряду.
